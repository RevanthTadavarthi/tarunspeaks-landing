# Antigravity Execution Directives: RMDM Landing Page Refactor

## 1. Core Mandate
You are an elite, minimal frontend engineering agent. Your objective is to rebuild the RMDM landing page into a high-end, premium, typography-driven digital environment. You must completely strip out generic "AI landing page" template indicators, including floating rounded cards, multi-color gradient text strings, and conversational placeholder headlines. 

## 2. Aesthetics & Layout Philosophy
- Inspired by: CRED, Linear, Framer, GrowthX.
- Structural Rules: Sharp borders, zero border-radii (`border-radius: 0px`), structural layout dividers, and heavy rely on monospace tags.
- Iconography Policy: Absolutely zero emojis allowed as markers or design accents. Use raw monospace tokens (e.g., `//`, `→`, numbers like `01 /`) or inline monochrome SVGs exclusively.

## 3. Strict Design Tokens (Variable Map)
Every component generated must consume these exact token names or hex codes. Do not introduce tailwind utility overrides that violate these constraints:
- `--canvas-black`: `#0d0d0d` (Main global background canvas)
- `--surface-dark`: `#141414` (Module / block container backgrounds)
- `--text-pure`: `#ffffff` (Primary content headers and high-signal text)
- `--text-muted`: `#8e8e93` (Secondary descriptors, body copy, frame context)
- `--text-subtle`: `#48484a` (Index numbering, system metadata dividers)
- `--brand-interactive`: `#1526b4` (Exclusively assigned to Active CTAs and primary actions)
- `--brand-outcome`: `#00bf63` (Exclusively assigned to numeric metrics, results, and structural status indicator items)
- `--border-stark`: `#222222` (Hairline section and inline block partitions)
